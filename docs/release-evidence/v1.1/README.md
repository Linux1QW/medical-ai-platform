## Artifacts

| Artifact | Description |
|----------|-------------|
| Backend test results | `pytest tests -q` — full backend test suite |
| Frontend test results | `npm test` — Vitest + Playwright |
| Type check | `mypy app` — static type analysis |
| Lint | `ruff check backend/` — code quality |

| BM25 gate | `evaluate_bm25.py --validate-golden-only` — 42 cases, 6 categories |

Artifacts are retained according to the project's data retention policy (90 days for CI artifacts, permanent for release bundles).
